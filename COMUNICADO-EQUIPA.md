# Mensagem para a equipa

> **Envia só depois de teres instalado e testado tu primeiro.**

---

Pessoal, uma coisa nova para quem trabalha com o Claude Code.

Juntei num sítio só a forma como trabalhamos nos sistemas que já estão a ser
usados pela equipa — ler o código antes de mexer, confirmar o resultado no ecrã
final e não num "correu bem", nunca dar por feito o que não foi verificado.

A partir de agora o Claude passa a seguir essas regras automaticamente.

**O que precisam de fazer (uma vez só):**

Abrem o Claude Code e colam estas duas linhas, uma de cada vez:

```
/plugin marketplace add VHHerbst/claude-plugins
```

```
/plugin install protocolo-sniper@v2h
```

Aparece um ecrã a pedir confirmação — carregam Enter. Está feito.

**Depois disso não têm de fazer mais nada.** Quando eu atualizar as regras,
chega-vos sozinho. Não há versões a divergir nem ficheiros para copiar.

Se quiserem ver as regras a qualquer momento, escrevem `/protocolo-sniper`.

Qualquer dúvida digam.
